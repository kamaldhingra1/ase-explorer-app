# ASE Brand Guide v1.1

## Brand Model

- **ASE Shield** = Product brand identity. Use on every page, favicon, SharePoint, Teams, GitHub, and training material.
- **ASE Wheel** = Explorer ecosystem visual. Use for the map, Explorer explanation, architecture, and learning content.

## Palette

- Deep Navy: `#0B1220`
- Electric Blue: `#00A3FF`
- Agent Purple: `#8B5CF6`
- Amber: `#FFB020`
- Attack Red: `#FF4D4F`

## Usage

- Keep amber for selected navigation and active tabs.
- Use blue/purple for agentic system and TrustOps visuals.
- Use red/amber only for attack paths, risk escalation, or emphasis.
