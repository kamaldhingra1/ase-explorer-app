# ASE v1.2 Release Notes

## Theme
Framework-neutral risk and control guidance with Ask ASE Preview.

## Included

- Added **Explore • Understand • Secure** tagline under the ASE wordmark.
- Added dark ASE-themed container around the annotated wheel on the home page.
- Added **Ask ASE Preview**, a rule-based assistant for common questions about memory, tools, identity, runtime, prompt injection, incidents, and business impact.
- Added framework-neutral **Security Patterns** content and data file.
- Added Learning page for Security Patterns.
- Preserved the principle that ASE is standalone and not tightly coupled to SATF.

## Design Principle

ASE explains agentic AI threats, incidents, business impact, and defensive patterns in plain language. Framework mappings should be optional overlays rather than required understanding.
