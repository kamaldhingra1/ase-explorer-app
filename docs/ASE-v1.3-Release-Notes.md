# ASE v1.3 Release Notes

## Theme
Risk-to-Defense experience and v2.0 Copilot Simulator foundation.

## Included

- Added a dark-background homepage annotation image: `assets/images/ase-hero-annotated-dark.png`.
- Updated homepage hero hierarchy: `Agentic Security Explorer (ASE)` as the primary heading and `Explore the agentic AI attack surface` as the secondary heading.
- Made the ASE header logo clickable across pages so mobile users can return home easily.
- Added `data/risk-defense-map.json` for risk to business impact to security pattern mapping.
- Added `data/copilot-playbooks.json` as a local-only foundation for the future ASE Copilot Simulator.
- Added How to Defend, Business Impact, Related Incident Chain, and optional framework overlay sections inside Explorer risk details.
- Improved Ask ASE Preview responses and suggested next steps while keeping it local-only with no API dependency.

## Design Principle

ASE remains standalone and framework-neutral. Framework mappings are optional overlays, not required for understanding the Explorer.
