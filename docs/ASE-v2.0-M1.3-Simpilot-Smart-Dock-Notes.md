# ASE v2.0 M1.3 - Simpilot Smart Dock

## Updates

- Adds ASE3-aware positioning for Simpilot.
- Simpilot remains bottom-right by default.
- When an ASE3 node/details panel is visible on the right, Simpilot automatically shifts to bottom-left.
- When the details panel is no longer visible, Simpilot returns to bottom-right.
- Adds smooth left/right transition.

## Files to deploy

Required:

- `js/simpilot.js`
