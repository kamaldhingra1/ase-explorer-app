# ASE v2.0 Phase 2 - Simpilot Context Insight Enhancements

## Updates

- Fixes Key Insight fallback behavior for subsequent threat/risk selections in ASE3.
- Adds broader local risk detection for right-side node details, risk chips, threat items, pills, and list items.
- Adds richer deterministic insight routing for prompt, tool, memory, identity, data exposure, runtime, incident-chain, planning, and output-integrity risks.
- Changes the Key Insight close control from destructive hide to a reversible collapse/expand control.
- The control now shows `−` when expanded and `+` when collapsed, without requiring page refresh.
