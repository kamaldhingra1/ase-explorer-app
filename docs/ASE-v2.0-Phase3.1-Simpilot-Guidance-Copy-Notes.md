# ASE v2.0 Phase 3.1 - Simpilot Context-Rich Guidance + Copy

## Updates

- Upgrades Simpilot quick guidance buttons to use selected ASE3 node/risk context.
- `Explain Risk`, `Recommend Controls`, `Business Impact`, and `Incident Chain` now reference selected risk, component, impact, mitigation, defense patterns, and related chains where available.
- Adds `Copy Guidance` to copy the current Simpilot output as clean text.
- Keeps all behavior local in the browser with no API calls, storage, authentication, or external dependencies.
