# ASE v2.0 Phase 3.2 - Simpilot Mobile Optimization

## Updates

- Adds mobile-only shield launcher using the existing Simpilot shield/ring branding.
- Reduces mobile launcher to a compact circular 48px touch target.
- Reduces mobile expanded panel width and height so ASE3 remains usable.
- Uses compact mobile layout with smaller header, actions, output, and copy button.
- Hides the Ask Simpilot input on mobile to preserve working space.
- Keeps desktop Simpilot behavior unchanged.
- Extends ASE3 mobile smart dock so Simpilot moves bottom-left when right-side risk/detail content is active, and returns bottom-right when not active.
