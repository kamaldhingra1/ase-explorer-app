Suggested Learning Tracks

Executive Track

Focus on business impact, governance, accountability, and what leadership should ask before approving agentic AI use cases.

  • What can the agent do?
  • Who approved its authority?
  • What could go wrong?
  • How would we know?

Architect Track

Focus on runtime architecture, trust boundaries, control placement, identity, telemetry, and egress channels.

  • Map components
  • Identify boundaries
  • Map controls
  • Validate failure modes

Practitioner Track

Focus on threat scenarios, incident chains, mitigations, and tabletop exercises using the ASE2 Explorer.

  • Select a component
  • Review risks
  • Build chains
  • Discuss mitigations
